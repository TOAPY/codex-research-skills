# Unvendored reference assets

Source: https://github.com/ChenLiu-1996/figures4papers

The source had no explicit distribution license at packaging time. Third-party scripts, figures and previews are intentionally excluded. Nature core plotting tools and original templates are retained. After obtaining rights, use scripts/fetch-restricted-reference.py in the central repository to fetch a pinned upstream checkout into a separate local reference folder. Never copy it into this skills repository.
